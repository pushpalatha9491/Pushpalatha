# Padmanabham Pushpalatha — Portfolio

A responsive single-page developer portfolio created from the provided resume.

## Run locally
1. Open `index.html` in any modern browser.
2. No build tools or dependencies are required.

## Sections
- Hero / Introduction
- About
- Skills
- Projects
- Education
- Internships & Certifications
- Contact

## Personalization
You can add GitHub, LinkedIn, project demo links, project screenshots, and a profile photo directly in `index.html`.
